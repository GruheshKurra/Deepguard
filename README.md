# DeepGuard - Landing Page

A Next.js landing page for DeepGuard iOS app with a premium dark mode design.

## About

DeepGuard is an iOS application that detects deepfakes and AI-generated images with 100% on-device privacy. This repository contains the landing page built with Next.js, TypeScript, and Tailwind CSS.

## Features

- **Privacy-First Detection**: All AI analysis happens on-device using Core ML
- **Multiple Detection Modes**: Single image, bulk analysis (up to 50 images), video analysis, and live camera detection
- **Smart EXIF Analysis**: Detects 20+ AI generation tools through metadata
- **iCloud Sync**: Cross-device history sync using personal iCloud storage
- **Abuse Reports**: Document and track deepfake misuse cases

## Tech Stack

- Next.js 16
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide Icons

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
